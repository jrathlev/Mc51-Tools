5.5.1 - Changes: 2012-07-03
        - Start of simulator enabled even if no source is loaded
        - New command line option:
          - "/sim" will start the simulator immediately after opening all
            active sources loading the last program that was edited
          - "/sim:<name>.<omf|hex>" will start the simulator and load the specified
            binary file immediately after opening all active sources
      - Bug fixes: 2012-07-05
        - ISP programming for 89S5x fixed (clock signal)
        - Loading of OMF-51 files fixed (erroneous evaluation of SegInfo)
        - When changing between IDE and simulstor the simulator windows
          lost its focus (SetWindowsPos instead of BringToFront)

5.5.0 - New: 2012-06-28
        - It is possible to load hex files into the simulator. Associated
          symbols are loaded from an mcu file of the same name or any other
          selectable file.
      - Changes: 2012-06-28
        - mcu files with spaces instead of tabs are accepted
        - Two loadable symbol tables (mcu files): user defined and basic
          Loading order: OMF51, User, Basic
          Already assigned symbols will never be overwritten, values already
          assigned to a symbol will not be redefined
      - Bug fixes: 2012-06-27
        - Signature for Atmel AT89S51 fixed
        - Loading of bit addressable locations from mcu file fixed.

5.4.4 - Changes: 2012-05-07

        - Jmp commands may have optionally an alternate number of cycles for

      - Bug fixes: 2012-05-07
        - Error loading opcodes and symbols fixed

5.4.3 - Changes: 2012-04-20
