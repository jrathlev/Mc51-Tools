Command line options

Having started the program via a desktop shortcut or having invoked it from another program, you can control it by setting the following command line options. The command line options can also be used to organize projects containing more than one source file (see at end of page).

none
The MC51 program will reload all files opened in the previous session.
[<Source1>] [<Source2>] ..
The MC51 program will only load the specified source files.
/term [<Filename>.hex]
Start the program in terminal mode and prepare the download of the optional denoted Hex file.
/sim[:<Filename>.omf|hex]
If no filename is specified, the MC51 program will start the simulator immediately after opening all active sources loading the last program that was edited. If an OMF or Hex filename is specified, the MC51 program will start the simulator and load the specified binary file immediately after opening all active sources.
/ini:[<Filename>]
By default the user configuration is saved in the file Mc51.ini. This file is located in the Application Data directory of the user:
  • Vista, Windows 7,8,10 and 11: C:\Users\<Username>\AppData\Roaming
  • Windows 2000 and XP: C:\Documents and Settings\<Username>\Application Data
Using the "ini" option, allows you can to select an alternative configuration file at any other location (e.g. E:\MyConfiguration\mc-1.ini).
/project:<project name>
Specifies the name of the project
/main:<main file>
Specifies the main file of the project
/compiler:<n>
Specifies the compiler type: 0 = Assembler, 1 = Pascal, 2 = C
/options:<options>
Specifies the options for the Turbo51 compiler
/coptions:<options>
Specifies the options for the C compiler
/memalloc:CodeStart;CodeSize;ExtStart;ExtSize
Specifies the memory allocation (code and Extended RAM) as hex or decimal values (only required for C programs).
Example: /memalloc:$8000;$01000;$9000;$01000
@<ProjectFile>
The command line options are loaded from a project file with the following structure: 
    ; comment
    /project:<project name>   ; name of the project
    /compiler:1                     ; Pascal
    /main:<mainfile>          ; main file of the project
    /options:-A -J -T
    <source1>                 ; source files
    <source2>
    ..
