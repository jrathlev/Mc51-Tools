## Notes about localization (po files)

The program is localized using [GnuGetText for Delphi](https://github.com/jrathlev/GnuGetText-for-Delphi).

The required PO files for the main program are located in this directory under the name *default.po*.
The PO files for localizing the dialogs and units used in the programs can be found in my
[Delphi-Program-Collection ](https://github.com/jrathlev/Delphi-Program-Collection).
