# MC51-Tools

The program package contains an **Integrated Development Environment** (IDE) for the **8051 family of microcontrollers** (Siemens, Philips, Atmel, etc.).

### The MC-51 IDE provides
- a text editor with syntax highlighting for the creation of Assembler, Pascal, and C sources
- an interface to the Pascal compiler Turbo51 by Igor Funa
- an interface to the assembler ASEMW by W.W. Heinz
- an interface to the C compiler SDCC (sdcc.sourceforge.net/)
- an integrated simulator and debugger for all basic 8051 functions including timer and serial interface
- a Terminal window for communicating with a monitor program inside the microcontroller and for downloading programs into the memory of the microcontroller using Hex Intel format
- a module for flash programming the Atmel AT89S51, AT89S52, AT89S8252 and AT89S8253 microcontrollers using the serial interface
        
### Additional Programs        
- Project manager
- Checking the ISP feature of Atmel microcontrollers and reading the program memory
- Verifier for flash programmings using ISP for Atmel microcontrollers
