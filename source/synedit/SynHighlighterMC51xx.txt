SynHighlighterMC51xx.pas
========================
This is a SynEdit-Highlighter for 51-family microcontrollers.
To use it for a specific member of this family the appropriate special
function registers (SFR) definitions must be loaded from a text file
(<name>.mcu). A set for the most common types is included.
Loading of this file is done by "InitHighlighter(Filename)".
